The tools

  • Hand-written HTML and CSS. No framework, no build step, nothing to install. If it renders, it's because the browser succeeded.
  • The black starfield is a 32x32 PNG, tiled. The planet is a 48x48 animated GIF with sixteen frames of wireframe sphere.
  • One small script, and it exists for exactly one reason: the hit counter. It counts in your browser's local storage, because a counter that always shows the same number is just a picture of a counter. With no backend, I at least had to innovate.
  • The blinking text, the scrolling ticker and the pulsing NEW badge are CSS animations, and they all stand down if your system asks for less motion.
  • The layout is flexbox under the skin, because I would like the page to be readable in 2026 as well as looking like 1998.

The window around the page

You are looking at this page inside a window. That window is a simulated Netscape Navigator 4 sitting on a simulated Windows 98 desktop, which is itself the front page of my site.

The desktop, the icons, the taskbar and every window in it are plain HTML and CSS with a small amount of jQuery. The bevels, the title bars and the buttons come from 98.css, the icons are from Windows 98 Icons by Alex Meub, and the desktop layout itself was inspired by MrRedShark77's page.

You can drag the window, resize it from the bottom-right corner, minimize it to the taskbar, and open the MS-DOS prompt on the desktop. Type HELP there.

Browser support

Anything modern the starfield is not pixelated, that is all
Lynx, w3m, screen readers this page is real markup, so it reads fine
