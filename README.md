# devinaxo.github.io

Heavily inspired (if not straight up plagiarized) by [_MrRedShark77's_](https://mrredshark77.github.io/) github.io page, but since I don't know jack of javascript I tried making it with a heavier focus on html and css, keeping javascript to a minimum. (Proud to inform I did learn valuable js while making this)


## The little retro site in web/
Double clicking the Résumé icon on the desktop opens a simulated Netscape Navigator 4
window, which loads the hand-made site in `web/`: a starfield background, a hit counter
that actually counts, a guestbook, skill meters and the long version of my work
experience. It is also a real site on its own at `/web/`, so the résumé is readable
without the desktop, and it is the only part of the project that is real content rather
than a joke about Windows 98.

Everything in there is plain HTML and CSS except `web/retro.js`, which exists only to
keep the counter, and `web/guestbook.js`, which is the guestbook form posting through
the same EmailJS service as the Contact Me window on the desktop. Every page doubles as
a normal document: the headings, the links and the text all work with the desktop
turned off.
